# G-야크 쇼핑 경험 확장

2026년 10월 15일 · 사용자 요청에 따른 기존 사이트 확장 · 화면 14

## 목적과 유지할 기준

상품이 풍부하고 원하는 옷을 찾기 쉬운 브랜드 쇼핑몰로 발전시킨다. 승인한 밝은 회색·올리브·SUIT와 스크롤 히어로는 유지한다. 상품·가격·사진은 가상 브랜드의 창작 자료다. 후기·판매 순위·할인 전 가격·배송 혜택·인증·영업 정보를 꾸미지 않는다. 회원 항목 비활성, 실제 결제·접수 없음, 개인정보 미저장 유지. 외부 계정·유료 서비스 연결·배포 없음.

모바일 레퍼런스와 실제 구매·계정 동작은 확인하지 않았다. G-야크의 모바일은 자체 반응형 설계로 검수한다. 아크테릭스·골드윈 공식 페이지도 조사했으나 이번 구현의 핵심 근거는 위 두 사이트다.

## 연결되는 요구사항

- R04: 상품 9→24종. 아우터 7(패딩 3 포함), 상의 7, 팬츠 6, 용품 4. 기존 19색 컷 유지, 신규 15종 전용 컷 추가. 신상품 표시는 실제 이번 카탈로그 추가 항목에만 적용한다.
- R04·R11: 상품명 검색, 분류·색상·사이즈·가격 필터, 추천·신상품·낮은/높은 가격 정렬. 선택 조건을 주소에 기록해 새로고침·뒤로 가기에서 복원. 검색값은 HTML에 안전하게 표시하고 없는 결과에 초기화 경로 제공.
- R05: 기존 상세·색상·확대·옵션·사이즈표 재사용. 용품은 FREE 한 가지 사이즈, 옷의 표를 용품에 재사용하지 않음. 쇼츠·짧은 소매 등은 전용 창작 치수와 내부 출처를 기록한다.
- R06·R08: 관심상품과 최근 본 상품은 상품 ID만 이 브라우저에 저장. 로그인 불필요. 저장 차단 시 메모리 상태로 사용. 장바구니와 개인정보 처리의 기존 규칙 유지.
- R01·R10: 히어로 → 빠른 분류·신상품 → 생활 속 착용 → 주말 편집 컬렉션 → 스타일 노트·최근 본 상품 → 브랜드·푸터. 제품을 먼저 고르고 생활 맥락을 더 볼 수 있는 순서.
- R10·R11: 상품 레일은 자동 재생 없이 화살표·터치·키보드 사용. 스크롤로 드러나는 캠페인과 가벼운 관심상품 피드백. 움직임 감소·미지원은 정적 표시. 폼·가격·제품 이름을 애니메이션으로 가리지 않음.
- R10: 스타일 노트 2편, 쇼핑 가이드. 모든 카드·배너·버튼의 연결 목적지가 실제로 존재. 새 브랜드 표방·허구 연락처·가짜 고객 후기는 추가하지 않음.

## 디자인과 검수

기존 색상·글꼴·본문 16px·최대 폭 1280px와 48/32/20px 여백을 사용한다. 새로운 상품 사진은 투명 제품 컷으로 통일한다. 상품 정보는 항상 볼 수 있고 PC 호버는 보조 반응이다. PC 목록 4열·중간 3열·모바일 2열을 유지한다. 신상품 레일은 제품을 가로로 비교하며 자동 이동하지 않는다.

PC·모바일의 배치와 실제 검색·복합 필터·정렬·관심상품·최근 기록·의류/FREE 장바구니·주문 정보·오류·키보드·움직임 감소를 검사한다. 기존 히어로 CSS와 기능 회귀, 전체 이미지 로딩, 가로 넘침, 실제 한글 줄바꿈을 함께 확인한다. 확인 결과·미확인 환경은 VERIFICATION.md에 기록한다.
