문서와 화면 설계도의 연결

PRD의 요구사항 번호 R01부터 R12는 디자인 명세와 와이어프레임에서도 같은 의미로 사용합니다. 무엇을 만드는지, 어떻게 보여줄지, 무엇으로 완료를 확인할지가 이어집니다.

회색 영역으로 된 와이어프레임은 사진의 위치와 콘텐츠 순서를 보여줍니다. 사진·워드마크·스크롤을 승인한 뒤 전체 화면에 확장했습니다. 회색 도해는 내용의 위치와 순서를 보여주며, 실제 구현값은 디자인 명세의 최신 절을 따릅니다.

PRD · 무엇을 왜 만드는지

수정일: 2026년 10월 15일 · 버전: 1.6 · 상태: 전체 문구·배치 정리 및 PC·모바일 최종 검수 완료

최신 적용 범위는 화면 18이다. 쇼핑 경험 확장과 이 문서의 마지막 절을 함께 따른다. 번호가 붙은 이전 제작 기록은 해당 버전의 이력이며 최신 범위를 제한하지 않는다.

G-야크는 일상과 가벼운 야외활동에 어울리는 남녀공용 의류와 용품을 선보이는 가상 브랜드다. 홈페이지는 제품의 디자인을 이해하고, 자신의 생활에 대입하고, 상품을 선택하는 경험을 제공한다. 구매 과정은 사이트 안에서 체험하지만 실제 결제·주문 접수·배송은 발생하지 않는다.

이 문서는 무엇을 왜 만드는지를 정의한다. 같은 요구사항 번호 R01부터 R12를 디자인 명세서에서 사용해 모습·동작·검수를 연결한다. 확정사항의 근거와 작성자 제안은 결정 기록에 구분한다.

2. 핵심 사용자 흐름

  1. 홈페이지의 경량 패딩과 한글 메시지로 브랜드를 이해한다.
  2. 스크롤에 따라 제품이 크게 좌우로 이동하고 기울어지는 소개를 본다. 배경은 도심 → 설산 → 트레킹 → 차분한 색상 선택 순서다. 도심·설산·트레킹에서는 닫힌 모습을 유지하고, 마지막 색상 선택 장면에서 전면과 소매가 넓게 펼쳐진 상태로 마무리한다. PC와 모바일 순서는 같다. 풍경·열린 모습은 창작 연출이며 실제 등산 성능을 증명하는 자료가 아니다.
  3. 히어로에서 색상을 바꾸고, ‘제품 살펴보기’로 상품 상세에 이동한다. 선택 색상은 유지한다.
  4. 착용 이미지와 옵션을 확인하고 사이즈·수량을 선택한다.
  5. ‘장바구니 담기’를 누르면 드로어가 열린다. 상품·옵션·수량·합계를 확인한다.
  6. 쇼핑을 계속해 함께 입을 상품을 추가하거나 장바구니·주문 정보 화면으로 이동한다.
  7. 입력한 정보를 브라우저 안에서 확인하고, ‘주문 정보 확인 완료’ 화면에서 선택 내역을 본다.

다른 진입 흐름은 ‘일상 착용 장면 → 관련 상품’, ‘검색·전체·아우터·패딩·상의·팬츠·용품 → 상품 상세’, ‘브랜드 소개 → 컬렉션’이다. 회원가입 없이 모든 구매 체험이 가능하다.

완료 화면 문구는 작성자 제안이다. 화면에 데모·임시라는 표시를 넣지 않되 실제 결제 성공, 주문 접수, 배송 시작, 확인 메일 발송을 주장하지 않는다. 최종 버튼은 ‘주문 정보 확인’, 완료 제목은 ‘주문 정보를 확인했습니다’로 제안한다.

8. 제작 조건과 외부 서비스

새 유료 서비스·구독·소재는 구매하지 않는다. 정해진 마감일 없이 문서 → 대표 시안 → 수정 → 전체 제작 → 검수 순으로 진행한다. 기존 제공 도구의 사용 가능 범위 안에서 AI 자료를 만들고, 별도 비용이 필요한 기능을 자동으로 사용하지 않는다.

현재 단계는 전체 홈페이지의 로컬 검수 완료다. 기존 기획 폴더와 다른 프로젝트를 확인한 뒤, 외부 설치 없이 HTML·CSS·JavaScript로 구현했다. 정적 프런트엔드, 즉 브라우저에서 화면과 동작을 처리하는 구조이며 외부 서비스나 환경변수가 필요하지 않다.

외부 회원·결제·주소 검색·메일·DB·분석 서비스와 환경변수는 초기 범위에 필요하지 않다. 장바구니·선택 색상은 브라우저 내 상태로 관리하고 개인정보와 분리한다. 장바구니 저장 여부는 디자인 명세의 제안을 따른다. 공개 배포·새 계정·유료 서비스·개인정보 수집은 현재 승인 범위에 포함되지 않는다.

작업 폴더에는 기존의 다른 홈페이지와 미추적 파일들이 있다. G-야크는 Homepage_GYak 폴더에 별도로 준비한다. 기존 프로젝트나 파일을 삭제·변경하지 않는다. 현재 Git은 master, 커밋 없는 상태이며 이번 단계에서 commit·push·PR·merge·배포를 하지 않는다.

디자인 명세 · 모습과 동작

수정일: 2026년 10월 15일 · 버전: 1.6 · 상태: 전체 문구·배치 정리 및 PC·모바일 최종 검수 완료

최신 적용 범위는 화면 18이다. 쇼핑 경험 확장과 이 문서의 마지막 절을 함께 따른다. 번호가 붙은 이전 제작 기록은 해당 버전의 이력이며 최신 범위를 제한하지 않는다.

이 문서는 G-야크를 어떤 모습과 동작으로 만드는지 정리한다. 사용자가 선택한 생활형 방향과 기능을 바탕으로, 구현에 필요한 세부 값을 제안한다. 수치·문구·상품명·로고 형태는 대표 시안에서 확인하고 수정할 수 있다. PRD의 R01부터 R12를 같은 번호로 참조한다. 쇼핑몰 조사 근거·적용 원칙은 확장 기록에 연결한다.

1. 디자인 방향과 레퍼런스

선택한 방향은 편안한 생활형 아웃도어다. 밝은 회색과 차분한 올리브, 자연광의 착용 사진, 단정한 한글로 편안함·일상성·자연스러움을 전달한다. 고객이 “나도 평소에 이렇게 입을 수 있겠다”고 느끼게 한다. 전문 등반 장비나 할인 행사보다 실제 생활에 어울리는 모습이 우선한다. (R01, R10)

영상에서 가져올 원칙은 제품을 크게 보여주기, 제품이 화면에 머무르는 동안 설명 이어가기, 위치·크기 변화로 초점 바꾸기, 충분한 여백, 고정 메뉴다. 푸른 색감·원본 문구·로고·상품 사진·기술 수치는 복제하지 않는다. 레퍼런스의 실제 모바일 웹이나 클릭 동작, 렌더링 기술은 확인하지 못했다. 모바일 구성과 색상 선택은 새로 설계한다. (R02, R03)

사진을 주인공으로 두고 글자는 짧게 사용한다. 홈은 제품 중심 몰입, 넓은 생활 사진, 상품 비교, 짧은 브랜드 메시지로 리듬을 바꾼다. 상품 목록·상세·주문 화면은 감상보다 정보와 조작이 먼저다.

초기 대표 시안은 밝은 단일 테마로 제안한다. 자동으로 어두운 테마로 바뀌어 사진과 브랜드 인상이 달라지지 않게 한다. 이는 밝은 생활형 선택을 구체화한 제안이며 다크모드 기능은 초기 범위에 추가하지 않는다.

기본 왼쪽 정렬, 제품 중앙 배치를 병행한다. 히어로는 화면 전체에 배경을 두되 내용은 공통 양옆 여백을 따른다. 화면 상단의 헤더 공간을 예약하고 첫 내용이 헤더 아래로 숨지 않게 한다. 일반 섹션의 위·아래 여백은 같은 값을 사용한다. 선보다 여백으로 정보를 묶는다.

3. 홈의 섹션별 명세

3.1 헤더 (R04, R06, R08, R09)

  • 목적·우선순위: 브랜드 인식, 상품 이동, 장바구니 순. 구매 탐색이 항상 가능해야 한다.
  • 내용: G-YAK 워드마크 제안, 전체 상품·아우터·상의·팬츠·용품·저널·브랜드, 검색·관심상품·장바구니 실제 담긴 수량, 비활성 회원가입·로그인·마이페이지.
  • 배치: PC 높이 64px의 한 줄, 제품 이야기 위에서도 유지. 상품 선택을 가리는 별도 광고띠는 만들지 않는다.
  • 연결: 로고는 홈, 각 상품 메뉴는 해당 목록, 브랜드는 브랜드 페이지, 장바구니는 드로어.
  • 모바일: 높이 56px, 로고·메뉴 버튼·장바구니. 펼친 메뉴에 상품 분류·브랜드·비활성 회원 항목을 배치한다.
  • 동작: 현재 페이지를 표시하고, 키보드 포커스나 이동 대상이 헤더에 가려지지 않게 여유를 둔다.

3.2 히어로와 제품 이야기 (R02, R03)

  • 목적: 대표 경량 패딩의 형태를 감상하고, 도심과 바깥 풍경을 잇는 브랜드의 인상을 이해한다. 설산 배경은 분위기 표현이며 극한 등반용 성능을 주장하지 않는다. (2026-10-14 사용자 피드백 반영)
  • 제안 제목: “매일의 움직임을 가볍게”. 본문: “출근길부터 주말의 산책까지. 일상에 자연스럽게 어울리는 G-야크의 경량 패딩.” 문구는 가상 브랜드의 창작 카피다.
  • 자료: 에브리데이 라이트 다운의 기존 투명 배경 단독 이미지 3색, 같은 제품의 열린 모습 3색, AI 풍경 사진 3장(도심·설산·트레킹). 기존 이미지를 참조해 퀼팅·소매·후드·포켓·색을 이어간다. 열린 컷은 1000×1200 투명 WebP, 배경은 PC 1600×900·모바일 768×432 WebP다.
  • 배치: PC 첫 장면은 제품을 중앙보다 오른쪽에 크게, 메시지는 왼쪽에 둔다. 상품명·색상·버튼은 하단의 밝은 가로 영역으로 모아 이동하는 제품과 분리한다. 중간·모바일은 메시지 위, 제품 가운데, 구매 조작 아래다. 모바일 하단 버튼은 가로 전체 폭이다.
  • 높이: 첫 장면은 화면 높이를 기준으로 헤더 공간을 제외해 구성한다. 전체 소개 구간은 4단계, 약 4화면 분량을 시작 제안값으로 둔다. PC·모바일 모두 같은 4단계다.
  • 우선순위: 제품 → 핵심 제목 → 색상 → 상세로 이동하는 버튼. 설명은 장면마다 짧게 바뀌며 자동으로 지나가지 않는다.
  • 버튼: ‘제품 살펴보기’ → 대표 상품 상세. 선택 색상을 전달한다. 히어로에서 사이즈를 고르거나 장바구니에 바로 담지 않는다.
  • 다음 구간: 마지막 색상 장면을 지나면 제품 고정이 풀리고 일상 착용 사진으로 이어진다. 임의 반복 재생이나 화면 맨 위로 되돌리는 동작은 넣지 않는다.
  • 모바일: PC와 같은 이동·확대·축소를 유지한다. 글자는 제품에 겹치지 않게 위·아래에, 색상과 버튼은 닿기 쉬운 하단에 둔다. 화면에 담을 수 없는 짧은 높이·확대 환경에서는 내용 전체를 자연스럽게 스크롤해 읽을 수 있도록 고정을 풀 수 있다.

3.3 일상 속 착용 모습 (R01, R05)

  • 목적·메시지: “내 일상에 어떻게 어울릴까?”에 사진으로 답한다.
  • 제목 제안: “평일에도, 주말에도”. 본문은 “도시를 걷고, 잠시 밖으로 나가는 날에도 자연스럽게.”
  • 자료: 성인 남녀 모델의 출근·산책·여행 사진. 단정한 보통 옷차림, 과한 등반 장비 없는 생활 장면.
  • 배치: 넓은 출근 사진 1장과 크기가 다른 산책·여행 사진 2장. 사진을 같은 카드 3개로 반복하지 않는다.
  • 우선순위: 전체 착용 인상 → 상황 설명 → 입은 상품 확인. 판매량·후기·유명인 추천을 근거처럼 넣지 않는다.
  • 연결: 사진 자체와 사진 아래 링크로 착용 색상이 선택된 대표 패딩 상세에 이동한다. 출근 사진은 기본 올리브로 연결하고 아래에 ‘올리브 보기’·‘스톤 보기’를 함께 제공한다. 산책은 스톤, 주말은 차콜로 연결한다. 사진의 팬츠까지 동일한 상품이라고 주장하지 않는다.
  • 실제 연결 UI: 사진 링크는 전체 면적과 모서리 12px을 유지하며 포커스 테두리가 잘리지 않게 사진 바깥에 배치한다. 출근 설명 아래 색상 링크는 14px·높이 44px 이상, 가로 간격 20px·줄 간격 4px, 설명과 간격 12px. 좁으면 링크가 줄바꿈된다. 새 창·팝업 없이 기존 상세 경로를 재사용하고 브라우저 뒤로 가기로 이전 사진 위치에 복귀한다. 사진 위에 버튼을 덮지 않는다.
  • 앞뒤 연결: 단독 제품에서 실제 착용 모습으로 확장하고, 다음 컬렉션에서 선택할 옷을 찾게 한다.
  • 모바일: 출근 → 산책 → 여행의 세로 순서. 사진 아래 관련 상품 버튼을 항상 보여주며 마우스 올림에 의존하지 않는다.

3.4 컬렉션과 추천 상품 (R04, R05)

  • 목적·메시지: 마음에 든 스타일을 실제 상품 선택으로 연결한다.
  • 제목 제안: “일상에 맞춰 골라보세요”. 필요한 경우 한 줄의 설명만 둔다.
  • 자료: 패딩·상의·팬츠 분류 사진과 추천 상품 4종의 단독 이미지·상품명·설정 가격.
  • 배치: 분류 진입은 대표 패딩의 넓은 이미지와 상의·팬츠의 작은 영역으로 비중을 달리한다. 추천 상품은 비교에 적합한 일정한 4열이다.
  • 우선순위: 사진 → 상품명 → 가격 → 제공 색상. 과장된 할인·품절 임박·구매자 숫자는 넣지 않는다.
  • 연결: 분류는 해당 목록, 상품은 상세, ‘전체 상품 보기’는 /shop.
  • 앞뒤 연결: 생활 장면에서 보던 의류를 선택하게 하고 다음 브랜드 메시지에서 공통 디자인 이유를 전달한다.
  • 모바일: 분류는 위아래 구성, 추천 상품은 2열. 이름은 최대 2줄 기준으로 공간을 예약하고 중요 정보는 잘라내지 않는다.

3.5 짧은 브랜드 소개 (R09)

  • 목적·메시지: G-야크가 일상형 아웃도어를 만드는 생각을 전달한다.
  • 제목 제안: “밖을 향해, 일상에 가깝게”. 본문은 “특별한 날을 기다리지 않아도 입기 좋은 옷. G-야크는 일상과 야외의 경계를 자연스럽게 잇습니다.”
  • 자료: 편안한 두 사람의 생활 장면 또는 옷의 형태를 보여주는 사진. 전부 가상 브랜드의 창작 자료다.
  • 배치: 단순한 사진과 짧은 문구를 배치해 상품 비교 후 화면의 밀도를 낮춘다. 브랜드 역사를 길게 만들지 않는다.
  • 우선순위·연결: 브랜드 생각 → ‘G-야크 이야기’ → /brand.
  • 모바일: 사진 다음 문구, 같은 읽기 순서. 긴 영문 슬로건으로 본문을 대체하지 않는다.

3.6 푸터 (R04, R09, R10)

  • 목적: 마지막에 필요한 곳으로 다시 이동할 수 있게 한다.
  • 내용: 브랜드명, 상품 분류, 브랜드 소개, 상품 상세에서 제공하는 사이즈·관리 안내의 위치. 실제 정보가 없는 주소·전화번호·사업자번호·SNS 링크는 꾸미지 않는다.
  • 배치: PC 3개의 정보 그룹, 모바일 세로 그룹. 관련 링크와 브랜드 문구만 넣는다.
  • 연결: 실제 존재하는 페이지·구간만 연결한다. 장식용 아이콘에 빈 링크를 만들지 않는다.

상품 상세의 사진은 기본 세로 배열과 썸네일 선택으로 제안한다. 여러 사진을 넘기는 장치가 필요하면 캐러셀, 즉 이미지를 순서대로 넘기는 장치를 사용하며 값 조절용 슬라이더와 구분한다. 자동 재생하지 않는다. 기본 시안에서는 자동 캐러셀이나 값 조절 슬라이더를 추가하지 않는다.

사이즈·관리 안내는 아코디언, 즉 제목을 누르면 아래 설명이 펼쳐지는 방식으로 제안한다. 별도 팝업을 중첩하지 않고 같은 화면에서 읽는다. 사이즈 표는 작은 화면에서 한 옵션의 치수를 묶어서 보여주어 전체 페이지 가로 스크롤을 만들지 않는다.

브랜드 소개는 “일상에 어울리는 형태”, “겹쳐 입기 쉬운 구성”, “밖의 시간과 연결되는 스타일”의 창작 원칙을 설명한다. 설립연도·실제 제작 공정·친환경 인증·수상·시험 결과가 존재한다고 이야기하지 않는다.
