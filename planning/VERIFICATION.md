## 초기 표시 성능의 로컬·모의 측정

캐시를 끈 1440×900 Chrome, CPU 속도 제한 없음. 실제 방문자 데이터가 아닌 한 번의 실험이다.

| 조건 | 주요 콘텐츠 표시 시간 LCP | 배치 흔들림 CLS | 50ms 이상 작업 |
|---|---:|---:|---:|
| 로컬 네트워크 | 0.248초 | 0 | 0회 |
| 모의 4G: 내려받기 1.6Mbps·지연 150ms | 2.436초 | 0.00637 | 0회 |

LCP는 가장 큰 콘텐츠가 나타나는 시간, CLS는 의도하지 않은 배치 변화다. 측정 조건에서는 제안한 2.5초·0.1 기준 안에 있었지만 기기·네트워크·실제 방문자 전체의 결과를 보장하지 않는다. INP와 현장 성능은 미확인이다. [조건과 원본 수치](../outputs/performance-check.json)를 보관했다.

## 파일과 Git 상태

변경·생성은 `Homepage_GYak` 안에서만 진행했다. 다른 홈페이지와 기존 미추적 파일 유지. 브랜치 `master`, 커밋 없는 상태. commit·push·PR·merge·공개 배포·새 유료 서비스 구매·외부 계정 개설 없음. Git의 전역 ignore 읽기 권한 경고는 기존 샌드박스 상태이며 설정을 수정하지 않았다.

기획 문서 버전 0.3과 이미지 출처·최종 요청을 함께 갱신했다. 공개 배포·실제 판매 연결에는 별도 요청과 설정 확인이 필요하다.
