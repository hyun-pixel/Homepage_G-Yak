# G-야크 홈페이지 결정 기록

수정일: 2026년 10월 15일 · 버전: 1.6 · 상태: 전체 문구·배치 정리 및 PC·모바일 최종 검수 완료

최신 적용 범위는 화면 18이다. [쇼핑 경험 확장](EXPANSION_V14.md)과 이 문서의 마지막 절을 함께 따른다. 번호가 붙은 이전 제작 기록은 해당 버전의 이력이며 최신 범위를 제한하지 않는다.

인터뷰에서 선택한 내용과 작성자가 구체화한 제안을 구분한다. 기획 방향 확인 뒤 사용자가 “좋아 진행해”라고 답해 대표 시안 제작을 승인했다. 이후 사용자가 ‘1번’으로 전체 페이지 확대를 승인했다. 공개 배포 승인은 별도다. [PRD](PRD.md)와 [디자인 명세서](DESIGN_SPEC.md)의 기획 결정과 실제 시안의 구현값을 함께 기록한다.

### 시안 제작 중 구체화한 제안

- 보조 글자 `#5C6656`으로 히어로 대비 보완.
- 실제 옷·한글 길이에 맞춘 48–64px/32–36px 제목, 짧은 화면의 제품 크기, 중간 화면의 고정 연출 기준.
- 활성 메뉴는 존재하는 컬렉션·다운·브랜드 구간에 연결. 최종 상품 분류는 R04대로 다음 단계에서 구현.
- 제품 보기는 현재 대화상자. 선택 색상을 유지하고 옵션·장바구니를 확인. 독립 상품 상세 페이지를 없애기로 결정한 것은 아님.
- 무료 SUIT·Phosphor 자체 제공, 기본 도구로 제품 3색·착용 사진 3장 생성. [자료 기록](../assets/ASSETS.md)에 출처·요청 보관.
- 다음 사용자 결정: 사진·제품 크기·문구·스크롤 길이 피드백과 나머지 페이지 제작 진행 여부.

## 6. 전체 제작 승인과 완료

2026년 10월 13일 사용자의 ‘1번’: 승인한 대표 시안의 분위기와 스크롤 연출을 기준으로 나머지 페이지 제작 진행.

- 확정 방향 유지: 생활형·남녀공용, 밝은 올리브, 한글 중심, 회원 항목 클릭 불가, 실제 결제 없이 사이트 내부 흐름.
- 구현: 9종·19개 색상 컷, 3분류, 독립 상세·브랜드·장바구니·주문 정보·확인 완료. 메인에 컬렉션과 브랜드 마무리 추가.
- 구현 선택: 설치나 새 서버 없이 기존 HTML·CSS·JavaScript 유지. 주소는 `?page=...`로 구분해 재방문·앞뒤 이동 지원. 개인정보를 주소에 기록하지 않음.
- 안전한 데이터 범위: 로컬 저장은 상품 ID·색상·사이즈·수량. 기존 시안 장바구니도 유지. 개인정보는 화면에서만 입력 검증하고 지움.
- 가상 설정: 가격은 PRD의 값 유지, 사이즈 치수는 창작 자료. 실측·소재 인증·판매 이력·고객 후기·사업자 정보는 확인했다고 말하지 않음.
- 추가 사용자 자료나 외부 계정·환경변수는 필요하지 않음. 유료 서비스 구매·commit·push·PR·merge·배포 없음.
